# AI Job Copilot 🤖

An agentic AI-powered job search system that:
- discovers jobs
- evaluates fit
- tailors resumes
- generates PDFs
- stores learning memory

## Features
- Multi-agent architecture
- Vector memory (FAISS)
- Resume tailoring
- PDF generation
- Job ranking
- Application recommendation

## Tech Stack
- Python
- Streamlit
- Groq
- FAISS
- Sentence Transformers

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
